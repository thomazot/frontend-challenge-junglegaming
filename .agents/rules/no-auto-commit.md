# No Auto-Commit Rule

**CRITICAL RULE:**
You must NEVER run `git commit` or any other version control commands to save or commit changes unless the user EXPLICITLY asks you to "commit", "salve", or "comite". 
When you make changes to files, leave them as modified in the working directory. Inform the user of what you changed, and wait for their explicit instruction before committing.
